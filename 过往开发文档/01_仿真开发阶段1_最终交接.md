# 仿真开发阶段1最终交接

> 本文档记录“阶段1：环境规格冻结”的最终结果。后续允许根据自检结果校准少量数值参数，但不随意改变已经锁定的时间语义、Observation、Action、Reward 与终止逻辑。

# 1. 训练结构

训练由多个 Episode 组成，每个 Episode 内包含多个 Step。

```text
Training
|
|-- Episode 1
|   |-- reset()
|   |-- step 1
|   |-- step 2
|   `-- ... <= 500
|
|-- Episode 2
|   `-- ...
|
`-- Episode N
```

每个 Step：

\[
\Delta t=0.2\text{ s}
\]

每个 Episode 最长：

\[
500\text{ steps}=100\text{ s}
\]

`reset()` 只重置环境，不清除已经学习的网络参数。

# 2. 系统节点与中继数量

固定逻辑链：

\[
H\rightarrow R_1\rightarrow\cdots\rightarrow R_K\rightarrow L
\]

- H：移动空中源节点；
- L：移动空中任务节点；
- R1 到 RK：RL 控制的中继 UAV；
- H、L 由环境控制。

K 必须是环境可配置参数。主实验第一版：

\[
K=4
\]

单个 Episode 内 K 固定，不允许中途动态增加或删除 UAV。不同 K 的扩展能力放到后续论文级实验验证。

# 3. 场景范围

\[
x,y\in[0,2000]\text{ m}
\]

\[
z\in[100,300]\text{ m}
\]

H、L 初始任务距离采用三维欧氏距离：

\[
1000\le d_{HL}(0)\le1500\text{ m}
\]

# 4. reset() 最终规则

每个 Episode 开始时：

1. 读取 K；
2. 随机生成合法 H、L 三维初始位置；
3. 检查 H、L 三维距离；
4. 按 H 到 L 的三维连线生成中继基准位置：

\[
p_{R_i}^{base}=p_H+\frac{i}{K+1}(p_L-p_H)
\]

5. 正式训练时对中继基准位置加入小范围三维随机扰动；
6. 中继初速度：

\[
v_{R_i}(0)=[0,0,0]
\]

7. 为 H、L 生成初始 waypoint、巡航状态和速度；
8. 检查边界；
9. 检查安全距离；
10. 检查初始逻辑链是否全部连通；
11. 不合法则重新采样；
12. 合法后构造初始 Observation。

初始连通不代表初始最优，只要求给 RL 一个可学习的正常开局。

# 5. H、L 运动模型

采用 Constrained Random Waypoint（受约束随机航点）：

- 三维连续运动；
- 到达 waypoint 后生成下一 waypoint；
- 不强制停车；
- 不允许瞬间改变速度或航向；
- 采用有限加速度平滑过渡；
- waypoint 满足地图、高度和 H-L 任务尺度约束；
- waypoint 生成器不得根据当前中继位置故意降低任务难度。

H、L 当前候选水平巡航速度：

\[
v_{HL}^{xy}\in[6,10]\text{ m/s}
\]

典型值约 8 m/s。具体速度范围、垂直速度限制、航段长度和运行期间最大 H-L 距离 D_max 需要后续数值自检校准。

# 6. 中继 Action 与动力学

Actor 输出：

\[
u_i\in[-1,1]^3
\]

映射为请求加速度。

水平加速度：

\[
\|a_{xy}\|\le2\text{ m/s}^2
\]

垂直加速度：

\[
|a_z|\le2\text{ m/s}^2
\]

速度限制：

\[
\|v_{xy}\|\le20\text{ m/s}
\]

\[
-5\le v_z\le6\text{ m/s}
\]

候选速度：

\[
v_i^{cand}=v_i(t)+a_i^{req}(t)\Delta t
\]

施加速度上限后得到实际下一速度，位置采用：

\[
p_i(t+1)=p_i(t)+\frac{v_i(t)+v_i(t+1)}{2}\Delta t
\]

速度限幅属于运动学约束，不属于 Safety Filter。

# 7. Actor Observation

第 i 个中继的基础局部 Observation：

\[
o_i=[p_i,v_i,\Delta p_i^{up},\Delta v_i^{up},C_i^{up},\Delta p_i^{down},\Delta v_i^{down},C_i^{down},\Delta p_i^{safe},\Delta v_i^{safe}]
\]

其中 safe 表示最近的非通信空中节点。

总维度：

\[
\dim(o_i)=26
\]

第一版不额外加入：

- 原始 SNR；
- outage flag；
- link margin。

这些量允许环境内部计算并记录，但不进入基础 Actor Observation。

Observation 输入神经网络前需要归一化；环境内部仍使用真实物理单位。

Graph 与 Role 信息不放入 Plain MAPPO 的基础 Observation。

# 8. Step 时间语义

一次 Step：

\[
o_t\rightarrow a_t\rightarrow\text{所有节点同步经历 }0.2\text{ s}\rightarrow s_{t+1}\rightarrow\text{安全/通信评价}\rightarrow r_t\rightarrow o_{t+1}
\]

所有下一状态都从同一个旧状态计算，最后统一形成新状态。

禁止先把 H、L 更新到未来时刻，再让 Agent 用未来 H、L 状态进行当前决策。

Reward 使用动作执行后的新状态计算。

# 9. 通信模型

三维距离：

\[
d_{ij}=\sqrt{(x_i-x_j)^2+(y_i-y_j)^2+(z_i-z_j)^2}
\]

信道增益：

\[
h_{ij}=\frac{\beta_0}{d_{ij}^{\alpha}}
\]

SNR：

\[
\gamma_{ij}=\frac{Ph_{ij}}{BN_0}
\]

容量：

\[
C_{ij}=B\log_2(1+\gamma_{ij})
\]

第一版通信初值：

- B = 10 MHz；
- P = 20 dBm；
- N0 = -169 dBm/Hz；
- beta0 = -60 dB at 1 m；
- alpha = 2。

这些需要通过数值自检确认公里级场景下的 SNR 和 throughput 是否合理。

# 10. DF + TDMA

采用帧内顺序半双工 DF + TDMA，不使用跨 Step 缓存。

解析 TDMA：

\[
\tau_i^*=\frac{1/C_i}{\sum_j1/C_j}
\]

端到端服务速率：

\[
R_{\mathrm{e2e}}=\frac{1}{\sum_i1/C_i}
\]

TDMA 由环境解析计算，不由 RL 学习。

# 11. 硬断链

第一版环境必须存在硬断链判定。

任意逻辑链路：

\[
\gamma_i<\gamma_{\min}
\]

则 outage = True。

只要任意一跳 outage：

\[
R_{\mathrm{e2e}}^{effective}=0
\]

短时 outage 不立即终止 Episode。环境维护连续 outage 计数，恢复连通后清零。

第一版测试值：

\[
N_{\mathrm{out,max}}=25\text{ steps}=5\text{ s}
\]

达到后认为通信任务失败并终止。5 s 属于待校准参数。

# 12. 安全规则

硬安全距离：

\[
d_{\mathrm{safe}}=20\text{ m}
\]

检查：

- 中继与中继；
- 中继与 H；
- 中继与 L。

安全逻辑：

```text
安全区域
→ 风险预警区域
→ 硬安全违规
```

当：

\[
d_{\mathrm{safe}}<d_{ij}<d_{\mathrm{warn}}
\]

产生软惩罚，但 Episode 继续。

当：

\[
d_{ij}<20\text{ m}
\]

判定安全间隔违规：

- 给予任务失败惩罚；
- terminated = True；
- 记录 violation pair 和涉及的 Agent。

第一版不做复杂责任归因。d_warn 需要仿真校准。

# 13. 边界处理

真正越过硬边界：

```text
boundary violation
→ terminal penalty
→ terminated = True
```

不采用把越界位置简单 clip 回边界后继续运行。

# 14. Reward

使用团队共享 Reward：

\[
r_t^1=r_t^2=\cdots=r_t^K=r_t
\]

第一版结构：

\[
r_t=\frac{R_{\mathrm{e2e}}^{effective}(t+1)}{R_{ref}}-\lambda_o I_{outage}-P_{warn}-\lambda_T I_{failure}
\]

第一版不加入：

- 真实推进能耗；
- 加速度运动代价；
- Safety Filter intervention penalty。

待校准：R_ref、lambda_o、lambda_T、d_warn。

# 15. Episode 结束规则

任务失败：

1. safety separation violation；
2. boundary violation；
3. persistent outage。

这些使用：

```text
terminated = True
```

正常达到 500 steps：

```text
truncated = True
```

# 16. 环境接口的概念理解

强化学习逻辑只有两层：Episode 和 Step。

`reset()` 开始一个新 Episode。

`step()` 在当前 Episode 中前进一个 0.2 s Step。

程序接口可采用 Gymnasium 风格：

```python
obs, info = env.reset()
next_obs, reward, terminated, truncated, info = env.step(actions)
```

这些返回值只是程序接口，不代表增加新的强化学习层级。

Episode 总回报由训练器累计：

\[
R_{episode}=\sum_t r_t
\]

# 18. 阶段1代码完成后的检查

代码完成后不能只检查“能不能运行”，必须做三层自检。

## 18.1 规则正确性

检查：

- reset 后所有节点是否合法；
- 初始通信链是否连通；
- Observation 是否为 26 维；
- K 改变后代码是否仍能运行；
- 同步状态更新是否正确；
- Reward 是否使用动作后的状态；
- terminated 与 truncated 是否正确区分。

## 18.2 运动学数值检查

用手工动作验证：

- 零加速度；
- 固定最大加速度；
- 水平速度上限 20 m/s；
- 上升 6 m/s、下降 5 m/s；
- 位置更新是否与受限后的速度一致。

至少画：

- x-y 轨迹；
- z-t 曲线；
- 速度-t 曲线；
- 加速度-t 曲线。

## 18.3 通信与安全数值检查

验证：

- 距离增加时 SNR 单调下降；
- 距离增加时容量单调下降；
- 弱链路获得更多 TDMA 时间；
- R_e2e 被最弱链路明显拖低；
- 硬断链门限在合理距离触发；
- 恢复连通后 outage counter 清零；
- 安全预警提前触发；
- 20 m 硬安全线准确终止；
- 越界准确终止。

通过后才进入 Plain MAPPO。
